# Project Delivery workflow

1. Read the approved business, data, architecture, evaluation, design, milestone, approval, evidence, state, and handoff records.
2. Identify the first approved unblocked milestone and preserve completed controls.
3. Audit real source and evaluation contracts before changing implementation.
4. Implement the smallest complete stakeholder workflow within the recorded privacy and authority boundary.
5. Add proportionate tests and update affected evidence, state, handoff, publication, metric glossary, and data dictionary records.
6. Run the production build and `python3 scripts/project_kit.py check`.
7. Stop at the next approval gate. Never infer authority to deploy, publish, spend, merge, change visibility, roll back, or transmit content to Graphify.
