# Project Delivery rule

Read `AGENTS.md`, `PROJECT.md`, `DESIGN.md`, and all `.project/` contracts before editing. Work only on the first approved unblocked milestone. Preserve privacy, licensed-data provenance, immutable evaluation lineage, and the no-lending-decision boundary. Keep evidence, state, handoff, and publication records current. Graphify transmission, cloud changes, deployment, publication, rollback, and spending each require their own recorded approval.
